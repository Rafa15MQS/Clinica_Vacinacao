# 💉 Sistema de Clínica de Vacinação

Projeto **Sistema de Clínica de Vacinação**, desenvolvido em Java e organizado com Maven.

## 📌 Sobre o projeto

O projeto está estruturado para o desenvolvimento de um sistema relacionado a uma clínica de vacinação.

O código-fonte Java, os recursos da aplicação e os arquivos SQL estão organizados no diretório principal do projeto.

## 🛠️ Tecnologias e ferramentas

- **Java** — linguagem de programação.
- **Maven** — gerenciamento e construção do projeto.
- **HTML** — arquivo da página inicial (`index.html`).
- **SQL** — scripts de banco de dados (`data.sql` e `clinica_vacinacao.sql`).

## 📂 Estrutura do projeto

```text
sistema-vacinacao/
│
├── src/
│   └── main/
│       ├── java/
│       │   └── com/clinica/sistema_vacinacao/
│       │
│       └── resources/
│           ├── templates/
│           │   └── index.html
│           │
│           ├── application.properties
│           └── data.sql
│
├── target/
├── HELP.md
├── clinica_vacinacao.sql
├── mvnw
├── mvnw.cmd
└── pom.xml
```

## 📄 Principais arquivos

| Arquivo | Descrição |
|---|---|
| `pom.xml` | Arquivo de configuração e dependências do Maven. |
| `application.properties` | Arquivo de configurações da aplicação. |
| `index.html` | Página HTML localizada na pasta de templates. |
| `data.sql` | Script SQL localizado nos recursos da aplicação. |
| `clinica_vacinacao.sql` | Arquivo SQL na raiz do projeto. |
| `HELP.md` | Arquivo de documentação auxiliar. |
| `mvnw` e `mvnw.cmd` | Scripts do Maven Wrapper. |
| `target/` | Diretório de arquivos gerados durante a construção do projeto. |
